## 1 实验内容

| 关卡 | 内容 | 结果及位置 |
| --- | --- | --- |
| 第一关 基本测试 | 8 位分组、10 位密钥、GUI 加解密 | 262,144 次往返通过；截图 01 至 03 |
| 第二关 交叉测试 | 比较加密输出，交换密文解密 | Python/C++ 的 262,144 组输出一致，35 组解密通过；与其他小组的交叉测试均通过 |
| 第三关 扩展功能 | ASCII 字符串逐字节加解密 | 128 个 ASCII 值和 256 个字节验证通过；截图 04、05 |
| 第四关 暴力破解 | 单组和多组已知对、全部候选、计时与动图 | 截图 06 至 10、brute_force.json、brute_force_demo.gif |
| 第五关 封闭测试 | 随机明密文的多解分析、任意明文的密钥碰撞 | 256 个明文均存在碰撞；报告中的抽屉原理分析与 collision_all_plaintexts.csv |

程序包含 21 项算法测试与 28 项界面检查。Windows 启动检查通过，记录见 `evidence/launcher_check.json`。

单文件 EXE 的 Windows 启动与默认加密自检通过，记录见 `evidence/executable_check.json`。
