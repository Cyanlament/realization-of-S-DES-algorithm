# 开发手册与接口文档

## 1. 模块边界

算法使用无 GUI 依赖的纯函数。`core.py` 负责分组变换，`encoding.py` 负责文本与字节，`analysis.py` 负责密钥穷举与碰撞统计。`gui.py` 只做输入输出与后台线程协调，`cli.py` 是同一业务接口的命令行入口。模块采用 `snake_case` 命名，关键位操作有注释；没有网络服务或数据库。

| 文件 | 职责 |
| --- | --- |
| `sdes/core.py` | 置换表、子密钥、轮函数、字节流加解密、教学跟踪 |
| `sdes/encoding.py` | ASCII/UTF-8 与 Hex/Base64/转义字节转换 |
| `sdes/analysis.py` | 已知明密文搜索、时间戳、取消、碰撞分组 |
| `sdes/gui.py` | PySide6 窗口与 `SearchWorker` 后台线程 |
| `sdes/cli.py` | 参数验证与 JSON 输出 |
| `reference/sdes_reference.cpp` | 独立字符串实现，不读取 Python 表或结果 |
| `tools/run_experiments.py` | 测试、编译、全量比对、统计与证据文件 |

## 2. 算法约定

所有置换从最高有效位起按 1 编号。10 位输入经过 P10 后拆成两个 5 位半部，分别循环左移 1 位，经 P8 得 K1；在移位后的半部上再循环左移 2 位，经 P8 得 K2。即第二子密钥相对原始半部共左移 3 位。报告明确展开流程，以消除简写公式中 `Shift^i` 的歧义。

S-box 输入是 4 位；外侧两位确定行，内侧两位确定列，表值编码为 2 位二进制。S1 与 S2 输出拼接后经过 P4。加密为 `IP -> f(K1) -> SW -> f(K2) -> IP^-1`；解密交换 K1/K2 顺序。

`SBOX2` 严格为 `((0,1,2,3),(2,3,1,0),(3,0,1,2),(2,1,0,3))`。这是与某些教材实现不兼容的关键差异。

为加速穷举，IP、逆 IP 和轮函数从公开的原始变换函数生成只读查找表，子密钥缓存最多 1024 组。`trace_block` 使用原始步骤展开；测试将它与快速路径逐一比较。参考 C++ 使用字符置换和字符串异或，不复用主实现代码。

## 3. 公共接口

从项目根目录可直接 `import sdes`。所有接口不修改传入对象，错误输入抛出 `ValueError`，CLI 转为退出码 2。

| 接口 | 参数与返回 | 错误条件 |
| --- | --- | --- |
| `parse_bits(text, width, name='输入')` | 二进制字符串 → 整数，忽略首尾空白 | 类型、长度、字符错误 |
| `generate_subkeys(key)` | 0..1023 → `(K1, K2)`，两个 0..255 整数 | 非整数、bool、越界 |
| `encrypt_block(plaintext, key)` | 0..255 与 0..1023 → 0..255 | 分组或密钥无效 |
| `decrypt_block(ciphertext, key)` | 参数范围同上，返回明文整数 | 分组或密钥无效 |
| `transform_bytes(data, key, decrypt=False)` | bytes → 等长 bytes；空 bytes 合法 | 不是 bytes、密钥无效 |
| `trace_block(block, key, decrypt=False)` | 返回输入、子密钥、IP、每轮步骤、输出的 dict | 分组或密钥无效 |
| `encode_plaintext(text, mode='ASCII')` | str → bytes；mode 为 ASCII/UTF-8 | 非法编码模式、字符不可表示 |
| `decode_plaintext(data, mode='ASCII')` | bytes → str | 非法编码模式、无效字节序列 |
| `render_ciphertext(data, mode='Hex')` | bytes → Hex/Base64/转义字节字符串 | 未知表示模式 |
| `parse_ciphertext(text, mode='Hex')` | 无损解析相应表示 → bytes | 奇数 Hex、非法 Base64、非法转义 |
| `parse_pairs(text)` | 每行 `P C` → `list[tuple[int,int]]` | 空列表、长度、列数或字符错误 |
| `brute_force(pairs, progress=None, cancelled=None)` | 已知对可迭代对象 → `SearchResult` | 空集或越界分组 |
| `collisions_for_plaintext(plaintext)` | 明文 → `{密文: tuple(密钥,...)}` | 明文越界 |

`SearchResult` 包含 `keys`、`checked`、`elapsed_ns`、`started_at`、`ended_at`、`cancelled`；`to_dict()` 将密钥转为 10 位字符串并增加 `elapsed_ms`。候选密钥升序返回，始终遍历整个空间，遇到首个候选不会提前停止。

`progress(checked)` 每检查 32 个密钥调用一次；`cancelled()` 在每个密钥前检查。中断结果只覆盖 `checked` 个密钥，必须结合 `cancelled` 判读。最坏时间复杂度 `O(1024 × m)`，m 为明密文对数；发现某对不匹配即跳过剩余约束。候选空间 `O(1024)`。

## 4. 使用示例

```python
from sdes import encrypt_block, decrypt_block
from sdes.analysis import brute_force
from sdes.core import transform_bytes

key = int('1010000010', 2)
cipher = encrypt_block(int('11010111', 2), key)
assert cipher == int('10001100', 2)
assert decrypt_block(cipher, key) == int('11010111', 2)
encrypted = transform_bytes(b'Hello', key)
assert transform_bytes(encrypted, key, decrypt=True) == b'Hello'
result = brute_force([(int('11010111', 2), cipher)])
assert key in result.keys
```

## 5. GUI 线程与测试

破解循环运行在 `QThread` 中，通过信号传回进度和 `SearchResult`，所有控件更新留在主线程。后台线程用于保持界面响应，不宣称绕过 Python GIL 或获得并行加速；本任务密钥空间很小，额外多进程启动成本通常不划算。

关闭窗口会发出中断请求并等待工作线程正常结束。错误输入通过状态文字展示，不弹出阻塞测试的对话框。不要在破解工作线程直接写控件。

```bash
python -m unittest discover -s tests -v
python tools/run_experiments.py
python tools/verify_vectors.py evidence/cross_vectors.json
python tools/gui_evidence.py
```

前两条只需标准库与 g++（仅全量实验需要 g++）；最后一条需安装 Qt。GUI 验证在 `QT_QPA_PLATFORM=offscreen` 下实例化真实控件，检查回调、线程、编码和结果；生成的是应用控件实拍式渲染，未模拟用户桌面的点击。Windows 离屏字体由已安装的微软雅黑/Consolas 显式注册，不将字体文件上传仓库。

## 6. 证据格式与复现

`summary.json` 汇总环境、测试数量、跨实现一致性和碰撞结果；`brute_force.json` 保存每一步候选和 30 次性能原始样本；`collision_all_plaintexts.csv` 有 256 行；`cross_vectors.json` 的字段固定为 `key/plaintext/ciphertext`。跨组输入格式相同，验证器不会修改输入文件。

重新生成图和报告需安装 `requirements-dev.txt`：

```bash
python -m pip install -r requirements-dev.txt
python tools/run_experiments.py
python tools/gui_evidence.py
python tools/make_animation.py
python tools/build_report.py
```

报告生成器读取现有 JSON，数值不硬编码为一次历史运行；运行测试后应同步重建报告。PDF 生成默认使用 Windows 已安装的微软雅黑，可用 `SDES_REPORT_FONT` 和 `SDES_REPORT_FONT_BOLD` 指定其他支持中文的 TrueType 字体路径。

GitHub Actions 在 Windows、Linux、macOS 的 Python 3.10/3.12 上运行核心、C++ 全空间交叉验证并归档证据。当前本地证据与远端 CI 结果分开记录，不能仅凭存在工作流文件宣称跨平台已通过。

## 7. 范围与后续扩展

TCP Socket 是作业给出的可选场景，本次完成了必做 ASCII 扩展并添加 UTF-8、三种密文表示和过程跟踪，未实现网络通信。以后可在明确消息边界的传输协议上复用 `transform_bytes`，但不要把 S-DES 当成真实安全通信方案。
