## 发布文件

`output/S-DES实验提交包.zip` 包含源码、Windows 单文件程序、打包配置、测试数据、截图、动图、Word/PDF 报告及使用文档。解压后双击 `dist/S-DES.exe` 即可运行。

`output/S-DES-submission.bundle` 是同一批文件的 Git 仓库包，可在本地克隆后推送。

```powershell
git clone --branch main .\output\S-DES-submission.bundle .\submission-to-push
git -C .\submission-to-push remote set-url origin https://github.com/Cyanlament/realization-of-S-DES-algorithm.git
gh auth login
gh auth setup-git
git -C .\submission-to-push push -u origin main
```

已有 GitHub 登录凭据时可跳过登录步骤。远端已有新提交而推送被拒绝时，先获取并合并改动，再推送。

推送后的 README 提供报告、程序和演示入口。Actions 页显示各平台的测试状态。
